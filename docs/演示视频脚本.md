# 演示视频脚本 — AI 英语朋友

> 时长：5–8 分钟（目标 7 分钟左右）｜分辨率：1080p（1920×1080）
> 要求：含 ≥2 分钟「AI 协同」演示
> 录制工具：Windows 自带「Xbox Game Bar」（Win + Alt + R）或 OBS Studio

---

## 录制前准备清单（务必先做）

- [ ] 关掉通知（微信/QQ/邮箱，避免录进弹窗）
- [ ] 桌面换成干净壁纸，或只开浏览器窗口
- [ ] 提前填好 DeepSeek API Key（避免视频里手输 Key 露出来，**打码/遮挡后再录**）
- [ ] 提前准备好要输入的句子，复制到剪贴板/记事本
- [ ] 录音时不要有环境噪音；如果配解说，用耳机麦克风
- [ ] 打开 App：`streamlit run app.py`，确认能正常对话
- [ ] 分辨率设为 1920×1080，Windows 缩放 100%（保证清晰）

> ⚠️ 重要：**全程不要露出完整 API Key**。侧边栏 Key 是掩码显示的（sk-…****），
> 但保险起见，录制侧边栏时把 Key 区域用马赛克/贴纸挡住。

---

## 完整流程（按时间轴）

### 第 0 段 · 开场（约 20 秒）

**画面**：打开浏览器，输入 localhost:8501，应用加载出来。

**解说词**（可选配）：
> 「这是『AI 英语朋友』，一个把英语老师、英国朋友、心理委员三种身份合在一起的 AI 学习伙伴。
> 我是李天恩，马鞍山学院软件工程大一的学生，这是我用 DeepSeek 和 GitHub Copilot 从零做出来的参赛作品。」

**操作**：
1. 展示页面标题「🤝 AI 英语朋友」和副标题
2. 鼠标点一下左上角 **☰ 菜单**，展示 7 个功能界面
3. 指一指顶部的**苹果红绿灯标题栏**（红黄绿三个圆点）——这是作者特别想要的细节

---

### 第 1 段 · AI 对话：看它「懂你」（约 1 分 40 秒）⭐核心

**操作 1 — 心理委员**：
1. 确认在「💬 AI 对话」界面
2. 输入：`今天好累啊，好烦`
3. 发送，等它流式回复
4. 指一指顶部出现的画像提示「🧠 我感觉到：🌧️ 你主要用中文为主 · 心情低落/需要支持」
5. 重点看它**温柔安慰、像心理委员**的语气

**解说**：
> 「注意看，它没有马上逼我学英语，而是先关心我的情绪——这就是它的『心理委员』身份。」

**操作 2 — 活泼切换**：
1. 再输入：`哈哈好开心！`
2. 发送，看它语气变得**活泼、有活力**
3. 指一指画像提示变成了「☀️ 积极/有活力」

**解说**：
> 「同样一个 AI，上一秒是倾听的朋友，这一秒是活泼的伙伴。它会根据我的情绪自动切换身份。」

**操作 3（可选，加时长用）**：
- 打开「🎭 角色设置」，展示猫娘「小棉」/鲸鱼娘「小汐」等角色

---

### 第 2 段 · 英语助手：语法改错（约 1 分钟）

1. 左上角 ☰ 切到「✏️ 英语助手 Tutor」
2. 选择「✏️ 语法改错」
3. 输入：`I very like AI, because it can help me a lot.`
4. 点「🚀 开始分析」，等它给出**正确句子 + 中文解释**

**解说**：
> 「这里我故意写了一句有语法错误的英文，它先给我正确的句子，再用中文解释错在哪、为什么。」

---

### 第 3 段 · 学习闭环：从改错到出题（约 1 分钟）⭐亮点

1. 改错结果出来后，点「🎯 针对刚才的句子出 3 道题」
2. 应用自动跳到「📝 做题本」，展示 3 道填空题

**解说**：
> 「这是整个作品我最得意的地方——改错不是终点。它会针对我刚才的错误，自动出 3 道题来巩固。
> 这就是一个『学习闭环』。」

---

### 第 4 段 · 做题 + 故意答错 + 批改 + 错题本（约 1 分 40 秒）⭐核心

1. 在 3 道题里**故意答错一题**（比如乱填一个明显错的答案），其余答对
2. 点「✅ 提交批改」，看它逐题批改、判断对错、讲解
3. 看底部提示「❌ 1 题做错，已自动加入错题本」
4. 点「❌ 去错题本看看」，展示错题被自动收集
5. 在错题本里**重新答对**这道题，看它「✅ 答对了！已从错题本移除，成长 +1」

**解说**：
> 「故意答错一道题，看看会发生什么——它批改完，把错题自动收进错题本。
> 我再重做一遍答对，它就从错题本里移除了。这样每次练习都有沉淀，不是做完就忘。」

---

### 第 5 段 · 历史记录：成长数字（约 30 秒）

1. ☰ 切到「📜 历史记录 History」
2. 指一指顶部的三个数字：**总练习 / 今日练习 / 待复习错题**
3. 简单往下翻几条记录

**解说**：
> 「所有练习都被记录下来了。看这个成长数字——总练了多少次、今天练了多少、还有几道错题待复习。」

---

### 第 6 段 · AI 协同演示（约 2 分钟）⭐比赛必含

> 这一段专门满足「含 ≥2 分钟 AI 协同演示」的要求。**二选一即可**，推荐方案 A。

**方案 A（推荐）：展示开发时的真实 AI 协作**
1. 切到浏览器另一个标签页 / 打开 DeepSeek 网页版 或 GitHub Copilot
2. 展示你和 AI 的**真实对话记录**（开发过程中问 AI、AI 给代码/改 bug 的对话）
3. 挑 1–2 个关键片段讲：比如「brotli 报错」是怎么和 AI 一起排查解决的

**解说**：
> 「这个作品不是我一个人写的。整个开发过程我都和 AI 结对——问它方案、让它帮我查 bug、一起打磨界面。
> 比如这个『流式回复报错』的问题，就是和它来回好几轮才定位到的。
> 我用 AI 不是让它替我做，而是和它一起做，最后代码我还是自己一行行看懂、改明白的。」

**方案 B：现场演示一次 AI 协同**
1. 在 DeepSeek 对话里现场问一个问题（比如「帮我看看这段代码有什么问题」）
2. 展示 AI 实时回答 + 你把它的建议改到代码里的过程

---

### 第 7 段 · 结尾总结（约 30 秒）

**画面**：回到应用主界面。

**解说**：
> 「这就是我的作品——一个会懂你的 AI 英语朋友。我是李天恩，一个零基础的大一新生。
> 从『我好像被同化了』到『我相信我自己』，这个 App 就是我走出来的证明。谢谢观看。」

## 录制小技巧

- 每段可以**分开录、再剪辑拼接**，不用一次录成（降低翻车率）
- 如果 AI 回复慢了，就多等两秒，剪掉多余空档
- 卡壳了不用慌，停一下重录这一小段就行
