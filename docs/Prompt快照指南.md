# AI 对话 Prompt 快照方案

> 比赛要求：提交「AI 对话 Prompt 快照」截图，**≥3 次核心迭代**。
> 作用：证明你在开发过程中与 AI 的真实协作（「AI 协同证据」）。

---

## 一、什么是「Prompt 快照」

就是你和 AI（DeepSeek / GitHub Copilot）**在开发这个作品时的真实对话截图**，
重点展示：你的提示词（Prompt）是怎么一步步迭代、引导 AI 做出更好结果的。

评审想看的是：**你不是一键生成，而是真的在「调教」AI、和 AI 反复打磨。**

---

## 二、要截什么（≥3 次迭代）

每个快照要能看出「这一次比上一次改进了什么」。建议按下面这条主线截：

| 迭代 | 主题 | 要截的内容 |
| --- | --- | --- |
| ① | 角色设定迭代 | 你问 AI「怎么做一个英语学习助手」，AI 给初版 → 你反馈「太生硬」→ AI 加入角色人设 |
| ② | 三位一体/情绪迭代 | 你提出「我想让它既像老师又像朋友，还能安慰我」→ AI 给出动态画像 + 情绪判断方案 |
| ③ | Bug 排查迭代 | 你贴出「流式回复报错」→ 来回几轮 → AI 定位到 brotli 冲突并给出 `Accept-Encoding` 修复 |
| ④（可选） | 界面/功能迭代 | 你让 AI 做「苹果红绿灯标题栏」「学习闭环」等，看需求一步步变清晰 |

> 只要 ≥3 张能体现「迭代进化」的截图就达标，3 张是底线，4–5 张更好。

---

## 三、怎么截

1. 打开你的 AI 对话工具（DeepSeek 网页版 / GitHub Copilot 聊天窗口）
2. 找到开发时那些关键对话（如果没保存，现在也可以**现场重新走一遍**：把当初的问题再问一次，截图新对话——只要内容真实反映你的思路即可）
3. 每张截图要**包含你的提问 + AI 的回答**，能看出完整的一问一答
4. 截图命名规范：`prompt-01-角色设定.png`、`prompt-02-三位一体.png`、`prompt-03-brotli修复.png`

---

## 四、每张截图配一句说明（重要）

评审不会自己猜，你最好在提交时（或一个说明文档里）给每张图配一句话，例如：

- **迭代①**：初版只是普通「英语老师」，语气生硬，我让它加入「朋友感」的角色设定。
- **迭代②**：我提出「三位一体」的想法，AI 帮我设计了根据用户情绪动态切换身份的方案。
- **迭代③**：流式回复中途报解压错误，和 AI 排查了多轮，最终定位到 brotli 压缩冲突，用 `default_headers` 修复。

---

## 五、可选的整理方式

可以把截图放进一个文档/PPT，也可以直接在提交平台按顺序上传并命名。
建议：建一个 `docs/screenshots/` 文件夹，把截图放进去，再写一个 `docs/Prompt快照说明.md`
把「每张图 + 一句说明」列出来，和截图一起提交。

---

## 六、注意事项

- ⚠️ 截图里**不要露出完整 API Key**（打码或裁掉）
- ⚠️ 不要露隐私信息（聊天里的私密内容、真实姓名地址等，只保留技术相关的对话）
- ✅ 真实即可，不需要「表演」，评审看重的是**真实的协作过程**
